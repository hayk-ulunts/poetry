ՀԱՅԿԱԿԱՆ ՊՈԵԶԻԱ — ընդհանուր կայք

index.html — գլխավոր ցանկը
 tumanyan-01.html — Հովհաննես Թումանյան, Հին օրհնություն
style.css — բոլոր էջերի ընդհանուր դիզայնը
player.js — ընդհանուր նվագարկիչը
assets/ — ձայնագրությունները և ապագա նկարները

Գլխավոր ցանկում բոլոր 9 ստեղծագործություններն են։ Հին օրհնությունը պարունակում է ամբողջ տեքստն ու ձայնագրությունը։ Մյուս 8 էջերը դեռ պարունակում են միայն հեղինակն ու վերնագիրը, մինչև նյութերը ավելացվեն։

Տեղային դիտում՝ բացեք index.html-ը, ապա սեղմեք Հին օրհնություն քարտը։

GitHub-ում առաջին տեղադրում
1. Ստեղծեք Public repository՝ poetry անունով։
2. Add file → Upload files։ Վերբեռնեք այս ZIP-ի բովանդակությունը (ոչ ZIP-ը կամ ընդհանուր պանակը)։
3. Commit changes։
4. Settings → Pages → Deploy from a branch → main → /(root) → Save։

Եթե հին տարբերակն արդեն տեղադրել եք՝ նույն repository-ում վերբեռնեք նոր փաթեթի ֆայլերը։ index.html, style.css և README.txt կփոխարինվեն։ assets-ի MP3-ը և player.js-ը նույնն են։ Ավելանում է tumanyan-01.html։
